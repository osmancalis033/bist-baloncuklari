# BIST Baloncukları Pro — GitHub Pages Sürümü

Bu klasör GitHub Pages üzerinde doğrudan yayımlanacak statik sunum sürümüdür.

## İçerik

- BIST baloncuk haritası
- Sektörel kümelenme
- Hisse detay paneli
- Fiyat ve hacim grafikleri
- Temel ve teknik analiz
- Pivot seviyeleri
- Tarayıcı, portföy ve karşılaştırma ekranları
- Kurum önerileri, konsensüs ve hedef fiyat görünümü

## Önemli not

Bu paket yatırımcı ve ürün sunumu amacıyla tarayıcıda üretilen sunum verilerini kullanır. Python sunucusu veya lokal bilgisayar gerektirmez. Gecikmeli gerçek veri entegrasyonu ayrı bir backend ile daha sonra bağlanabilir.

## GitHub Pages

Repository ayarlarında **Settings → Pages → Deploy from a branch → main / root** seçildikten sonra site yayımlanır.
